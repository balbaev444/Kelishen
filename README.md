### Secure Online Transactions. Built on Trust.

Kelishen is a secure online transaction platform designed to protect both buyers and sellers through an escrow-based payment system.

Our goal is to make online transactions safer, more transparent, and more reliable by ensuring that funds are released only when agreed conditions are met.

---

## About the Project

Kelishen introduces an escrow mechanism that temporarily holds buyer funds until the transaction is successfully completed.

The platform is designed to reduce fraud, build trust between users, and simplify secure online exchanges.

## Key Features

- **Escrow Protection** — funds are held securely until transaction conditions are fulfilled.
- **QR Verification** — dynamic QR codes for transaction confirmation.
- **GPS Verification** — location-based verification during handovers.
- **Photo Documentation** — visual evidence of an item's condition.
- **Dispute Resolution** — a mechanism for handling disagreements between parties.

## System Architecture

Kelishen is designed around a modular microservices architecture:

- API Gateway — centralized access and request routing.
- Escrow Service — transaction and fund management.
- Verification Service — QR, GPS and photo verification.
- Dispute Service — dispute management and resolution.
- Database Layer — users, transactions and related data.

## Development Roadmap

- **MVP** — Core platform functionality and escrow transactions.
- **v2.0** — Banking and payment provider integrations.
- **v3.0+** — AI-powered media verification, fraud detection and support for additional transaction types.
